Hane support

Support for the Hane Windows dictation app

Contact us

For technical support, privacy questions, or beta feedback, email hane.support@gmail.com.

If reporting a problem, it helps to include your Windows version, the Hane version, and a brief description of what happened. Please do not send API keys, passwords, microphone recordings, or confidential dictated text.

Privacy and data controls

Hane uses local speech recognition and offers optional provider-based text cleanup. See the privacy policy for information about logs, dictionary data, Windows Credential Manager, clipboard use, and how to remove stored information.
