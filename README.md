# Hane website

The public website for [Hane](https://soralabs.github.io/hane-site/), a push-to-talk dictation app for Windows published by Sora Lab.

## Pages

- `index.html`: home page
- `privacy.html`: Hane Privacy Policy
- `support.html`: support and contact

`PRIVACY-POLICY.md` is the plain-text version of the privacy policy. Keep it and `privacy.html` identical in wording, and update the effective date in both when the policy changes.

## Notes

- Plain HTML and CSS, served by GitHub Pages from the `main` branch. There is no build step.
- No scripts, analytics, trackers, external fonts or third-party resources.
- `favicon.ico` and `hane-mark-*.png` are Hane's application icon.

Questions: [hane.support@gmail.com](mailto:hane.support@gmail.com)
